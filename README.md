# HCL.ArticleService.API

Микросервис для управления статьями с интеграцией различных технологий.

## Описание проекта

Этот проект представляет собой микросервис для управления статьями, который включает:

- Хранение статей в MongoDB
- OData API для запросов к статьям
- Интеграцию с gRPC для получения информации об авторах
- Кеширование с использованием Redis
- Очереди сообщений через Kafka
- Фоновые задачи через Hangfire
- Логирование в Elasticsearch
- Аутентификацию через JWT

## Технологический стек

- .NET 7
- MongoDB
- OData
- gRPC
- Redis
- Kafka
- Hangfire
- Elasticsearch
- Docker
- xUnit (для тестирования)

## API Endpoints
### Основные endpoints
- **`POST /api/article/v1/article`** - Создание статьи
- **`DELETE /api/article/v1/article/account`** - Удаление своей статьи
- **`DELETE /api/article/v1/article`** - Удаление статьи (для админа)
- **`GET /api/article/v1/article/withAthor`** - Получение статьи с информацией об авторе
- **`GET /odata/v1/article`** - OData endpoint для запросов к статьям
### Аутентификация
Для доступа к защищенным endpoint'ам требуется JWT токен с соответствующими правами.
